Connect Four on an LED Matrix

DUT project · Year 2

Recreated Connect Four on a 64-LED NeoPixel matrix (8×8, serpentine wiring), using a 6×7 game grid. Each player's pieces light up in their color and fall down the grid; the four winning pieces blink at the end.

What I did

  • Wrote a coordinate-mapping function from the game grid to the 64 LEDs
  • Programmed piece drop animation and 4-in-a-row win detection
  • Added sound feedback and a color display of the winner

Motion Clouds – Research Internship

10-week internship · Jan–Mar 2025 · Laboratory of Neurodynamics and Vision, UFMG, Belo Horizonte, Brazil

Connected the Motion Clouds stimulus library to PsychoPy so the lab could run psychophysics experiments with neurodivergent participants (autism, ADHD).

What I did

  • Generated Motion Cloud stimuli frame by frame in Python
  • Wrote unit-conversion functions from pixels to degrees of visual angle
  • Built a complete experimental protocol: 54 conditions, 18 directions
  • Managed the code with GitHub and VS Code, working in English
